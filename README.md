# INKO Melbourne V3

Website for INKO Melbourne: a single-page site made of 11 full-screen stacked slides.

**`theme/inko-custom/` is the single source of truth for the website design.** The live site (`site/`) is a static
export of that WordPress theme, generated by `scripts/export-static.mjs`.

| Folder | What it is | How it runs |
|---|---|---|
| `theme/inko-custom/` | The WordPress theme the website is built from (PHP templates, CSS, JS, images, all business content in `inc/content.php`). | WordPress (LocalWP for editing). No page builder needed. |
| `site/` | Static export of the inko-custom homepage (`site/index.html` + `site/wp-content/themes/inko-custom/assets/`). | Vercel (or any static host). No PHP or database. |
| `api/quote.js` | Vercel function behind the quotation form (`POST /api/quote`). | Vercel serverless (Node). |
| `scripts/` | `export-static.mjs` (build `site/` from WordPress) and `preview.mjs` (test it locally with the real API). | Node 18+, no dependencies. |
| `theme/inko-melbourne/` | The previous theme (kept for reference; older pages such as `site/quote/` still use its assets). | — |

## Deploying the static site to Vercel

`vercel.json` tells Vercel to serve the `site/` folder as-is: there is no install or build step.

1. Import this repository at https://vercel.com/new.
2. Leave **Framework Preset** as **Other**, then click **Deploy**.

The pages use root-relative URLs (`/wp-content/...`), so the site must be served from the domain root (a normal Vercel domain or a custom domain both work).

## Quotation form

The quotation form is slide 09 of the homepage (fields: first/last name, email, phone, preferred artist, reference
file, details). On Vercel it posts to `/api/quote`; in WordPress the same form posts to `admin-post.php`. The older
standalone page `/quote/` (`site/quote/`) also posts to `/api/quote`
(`api/quote.js`), a Vercel serverless function that validates the request, checks the uploaded file's real type
(JPG, PNG, WEBP, HEIC or PDF, max 4 MB), and emails it to the studio through [Resend](https://resend.com) with the
file attached and **Reply-To** set to the client. The page shows "Thank you" only after Resend accepts the email.

Setup (required before the form can deliver anything):

1. Create a free Resend account **using the studio email** (`inko.melbourne@gmail.com`). Without a verified domain,
   Resend's test sender can only deliver to the account owner's address.
2. In Resend, open **API Keys → Create API Key** (permission: *Sending access*) and copy the key.
3. In Vercel, open the project's **Settings → Environment Variables**, add `RESEND_API_KEY` with that key for
   *Production* (and *Preview* if wanted), then redeploy.
4. Send one test request from the live `/quote/` page and confirm it arrives in the studio inbox.

Optional variables are listed in `.env.example` (`QUOTE_TO_EMAIL`, `QUOTE_FROM_EMAIL`). To send from an address like
`quotes@inkomelbourne.com.au`, verify that domain in Resend and set `QUOTE_FROM_EMAIL`.

In WordPress, the inko-custom theme handles the same form itself (`inc/quote-form.php`, sent with `wp_mail`); use an
SMTP plugin on a real WordPress host for reliable delivery.

## Using the WordPress theme

1. Zip the `theme/inko-melbourne` folder and upload it in **Appearance → Themes → Add New → Upload Theme**.
2. Install and activate the **Elementor** plugin.
3. Run **Appearance → INKO Setup** to create the Elementor homepage and import the images.

## Updating the website (inko-custom → Vercel)

1. Edit the **inko-custom** theme in LocalWP (`Local Sites/inko-melbourne/app/public/wp-content/themes/inko-custom`)
   and check it at http://inko-melbourne.local/.
2. Build a preview (copies the theme into `theme/inko-custom/`, renders the homepage, keeps only the theme's own
   assets, wires the form to `/api/quote`, and fails if any file reference is broken):
   ```
   node scripts/export-static.mjs --out .build/site
   ```
3. Test it locally with the real `api/quote.js` (emails are mocked and saved to `.build/last-email.json`):
   ```
   node scripts/preview.mjs --dir .build/site --mock-email
   ```
   Open http://localhost:4173/ and check the pages and the quotation form.
4. When it passes, export into the live folder, commit and push. Vercel redeploys automatically:
   ```
   node scripts/export-static.mjs --out site
   ```
